# SitKit pre-launch website preview

Public preview: <https://lennyacl12-art.github.io/sitkit-store/>

This static site is a concept preview for an editable pet-sitter and dog-walker business tracker. It does not take orders or payments, and it does not deliver the workbook. The product name, seller details, support channel, and sales policies still need to be finalized before selling.

The website source is public because the free GitHub Pages plan publishes from a public repository. The paid Excel workbook is not included in this repository or linked from the site.

The site uses plain HTML, CSS, SVG, and JavaScript. Its rate calculator runs in the visitor's browser. The Translate button opens Google Translate as a visitor convenience; it does not create separate translated pages for search engines.
