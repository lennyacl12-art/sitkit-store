All questions ↗
Can I buy the tracker now?

No. This is a pre-launch storefront preview. There is no live checkout or file-delivery service yet.

Does this include an app, contracts, or tax forms?

No. The product is a spreadsheet tracker and rate-planning calculator. It does not include scheduling software, legal forms, or tax advice.

Can visitors read the website in another language?

Use the language menu and Translate button to open Google's website translation flow. The translated view is machine generated and is not a separate, search-indexed language page.
